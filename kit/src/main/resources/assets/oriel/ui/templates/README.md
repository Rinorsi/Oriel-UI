# 官方模板源码

01—53 同层编号（52原型与44背景参考），旧版在 legacy/。每个 template.json 是该模板的元数据编辑入口，locales 自带中英文名称、介绍、分类；作者为云诺羲。当前语言 → 英文 → 中文 → 其他已有语言。

catalog.json 仅为自动生成的顺序与路径索引；不要在索引修改名称。执行 node tools/templates/sync.mjs 更新索引、说明及文件清单，不写全局语言文件。

源码在仓库与长期 archive 备份中，不受 daily 清理。
