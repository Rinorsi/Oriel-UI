打开全屏示例
配色
血法力青铜金
字体
oriel:smiley数值、伤害minecraft:default正文
用到的能力
border-radius 50%overflow 圆角裁切radial-gradienttransform 动画<item><entity>
做法

.orb { border-radius: 50%; overflow: hidden; }
.orb::before { border-radius: 42%;          /* 液面 */
  animation: slosh 6s linear infinite; }
@keyframes slosh { to { transform: rotate(360deg); } }

打开全屏示例
配色
友军敌方正常底
字体

用到的能力
repeating-radial-gradientconic-gradientmask-imagemask 合成@keyframes
做法
1雷达圈是重复径向渐变，扫描线是旋转的锥形渐变

.radar { background:

    transparent 0 10px, #7fe7ff40 10px 11px); }
.sweep { background: conic-gradient(
    transparent 0 290deg, #7fe7ff99 360deg); }

打开全屏示例
配色

字体

用到的能力

.light { animation: flicker 2.3s steps(1) infinite; }

.foes entity  { -mc-yaw: -55deg; }

配色

字体

用到的能力

做法

SYNTHWAVE未来科技落日沉入网格，玻璃面板、打字终端、分段能量环
打开全屏示例
配色
青光警示落日夜
字体
oriel:smiley标题、数值minecraft:default终端
用到的能力
backdrop-filterclip-path 切角repeating-conic-gradientmask 合成vertical-align 长度
做法
1地面是从消失点发出的重复锥形渐变，再叠一层越往下越疏的横线
2玻璃面板 = backdrop-filter 模糊 + clip-path 切掉两个角

.panel { backdrop-filter: blur(3px); clip-path: polygon(
  10px 0, 100% 0, 100% calc(100% - 10px),
  calc(100% - 10px) 100%, 0 100%, 0 10px); }

INK & PAPER修仙水墨群山、竖排书法、八卦太极、展开的卷轴与符箓
打开全屏示例
配色
墨宣纸朱砂青玉
字体
oriel:brush标题、符箓oriel:kai正文
用到的能力
writing-mode 竖排-webkit-text-strokeclip-path 山形transform-origin 卷轴
做法
1标题、印章和符箓都是 writing-mode: vertical-rl，从右往左一列一列排
2「金丹」是金色字加墨色描边；卷轴展开是从顶部 scaleY
3太极是左右各半的渐变，加上下两个带圆点的小圆
h1 { writing-mode: vertical-rl; font-family: oriel:brush; }
.realm b { color: #c99a3b; -webkit-text-stroke: 2px #1e1a16; }
.paper { transform-origin: top; animation: unroll 1.1s both; }
