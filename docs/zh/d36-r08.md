# Flex 布局迁移与求解诊断

[手册首页](index.md) · [CSS 参数](css-guide.md) · [性能规范](performance.md)

这里的开关用于开发者验证布局引擎，不是页面 CSS 或公共 Java API。当前默认仍为旧 Flex 实现。Grid 的命名线、基线与 subgrid 不因启用 Flex 候选实现而新增支持。

## 实现选择

JVM 参数 -Doriel.layout.flex=old|new|both，缺省 old，非法值直接报错。

| 值 | 行为 |
|---|---|
| old | 冻结的旧实现，作为迁移参照 |
| new | 候选实现；使用每次布局独占的 item 暂存池、单容器固有尺寸缓存、行切片与合并遍历 |
| both | 同一 DOM/样式建立独立旧、新盒树；逐浮点值比较所有盒矩形、边距、边框、内边距、基线、行与片段矩形；差异立即报页面、元素、盒路径、字段及旧/新值 |

both 共享宿主的纯文字度量缓存，**不共享盒子或尺寸约束测量缓存**。参照树不执行溢出汇总和滚动钳制，最终树只执行一次这些步骤。对拍会增加开销，不用于计时；也不比较 GPU 输出、声音或宿主扩展内部状态。

item 暂存池只活在一次 LayoutPass 内，递归测量期间借出的 item 不会被复用，退出容器后释放。内容尺寸缓存只活在该容器的固定宽高、确定性和百分比基准内，不跨帧、跨字体或跨样式复用。原有 CSS 语义与许可保留，不能把优化后的派生代码称为完全独立原创。

## why-size / why-position

在 new 或 both 下设置 -Doriel.layout.flex.trace=why-size|why-position|all。缺省 off，不创建事件或输出缓冲；非法值报错。

- why-size：每个 item 的 base、hypothetical、target、剩余空间、min/max violation、冻结状态与迭代序号。
- why-position：主轴/交叉轴最终偏移、行号、方向和对齐原因。偏移是 Flex 相对坐标，不是施加 relative/transform 后的视口坐标。
- all：同时输出两类事件，包含尺寸测量过程，可能出现同一容器多次求解。

缺省通过宿主 DEBUG 日志输出 JSON 对象；宿主可能添加日志前缀或在 quiet 模式隐藏它。设置 -Doriel.layout.traceFile=/absolute/external/flex.jsonl 可追加写入纯 JSONL。父文件夹须已存在，路径不可写时直接报错；该路径由启动 JVM 的开发者设置，页面无法指定。日志不要写进源码仓库。

    java -Doriel.layout.flex=both -Doriel.layout.flex.trace=all \
      -Doriel.layout.traceFile=/external/flex.jsonl \
      -cp "preview/build/install/preview/lib/*" dev.oriel.preview.Preview \
      page.html --snapshot /external/page.png --frames 20

JSON schema 为 1，包含 context/query/phase/source/container/item/sourceLine/line/iteration、尺寸与偏移字段、frozen/direction/reason。sourceLine 是 HTML 源行；line 是从 0 开始的 Flex 行编号；未定义的数值为 JSON null。reason 为人可读解释。文件使用追加模式，不自动清空、轮转或删日志。

这些是 JVM/预览器启动入口，尚无单独的 MCP why-size 工具。MCP 启动的 Java 子进程若继承这些 JVM 参数，可写相同日志；不能把设置开关当成已完成游戏诊断。

## CSS 边界与验证

gap 的两个值分别是 row-gap、column-gap，在 column 方向主/交叉轴互换；place-content 的两个值分别展开为 align-content、justify-content。这些是已有能力，迁移回归另覆盖了两个方向的换行与精确位置，没有增加或改变 CSS 注册项。

冻结的 Taffy 夹具及黄金图保持不变。迁移测试额外运行独立树对拍；页面测试在同一动画状态下比较 computed style 和 RGBA，覆盖两个窗口尺寸。它们不代表完整浏览器规范支持，也不替代游戏、GPU、中文输入法或多人环境验收。性能仅以独占窗口的交替采样判断，both/trace 的诊断开销不计入新旧生产路径的比较。

已知限制继续以 [CSS 参数](css-guide.md) 为准；命名 Grid 线、Grid 基线和 subgrid 的评估属于后续 Grid 切片，本次 Flex 入口不提供这些能力。
