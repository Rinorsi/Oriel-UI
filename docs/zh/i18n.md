# 多语言速查

库文案统一放在 `kit/src/main/resources/assets/oriel/lang/<locale>.json`，使用 Minecraft 标准格式。`zh_cn.json` 是源文案，`en_us.json` 提供英文；两份 key 集合一致。key 按页面组织，例如 `oriel.ui.gallery.start`，共用文案可用 `oriel.ui.common.*`。

## HTML：只写 key，保留元素与布局

```html
<button data-i18n="oriel.ui.gallery.start">oriel.ui.gallery.start</button>
<input placeholder="oriel.ui.gallery.search" data-i18n-placeholder="oriel.ui.gallery.search">
<div title="oriel.ui.gallery.close" data-i18n-title="oriel.ui.gallery.close">×</div>
```

`data-i18n` 替换首个非空直接文本节点，保留图标与其他子元素。混合内容用 `data-i18n-text-0="key"` 等指定 `childNodes` 的零起始索引，并把对应源文本换成 key。空元素会增加一个文本节点。
文案属性用 `data-i18n-<属性名>`：支持 `title`、`placeholder`、`alt`、`aria-label`、`value`、`data-title`、`data-toast`、`data-notice`、`data-notice-action`。class、id、资源路径、协议字段和数值仍是代码或数据，不翻译。

## CSS content

```css
.hint::before { content: i18n("oriel.ui.gallery.hint"); }
.count::after { content: i18n("oriel.ui.gallery.count.other", attr(data-count)); }
.count[data-count="1"]::after { content: i18n("oriel.ui.gallery.count.one", attr(data-count)); }
```

首参必须是带引号的 key；后续参数支持字符串、数字、`attr(name)`，依次填入 `%s` / `%1$s`。函数只生成文本，不改变样式与结构。

## Java、格式参数和复数

```java
Dom.text(label, Lang.t(document, "oriel.ui.gallery.saved", name));
Dom.text(countLabel, Lang.plural(document, "oriel.ui.gallery.count", count));
```

例如 `saved` 的中文值为 `已保存 %s`，英文为 `Saved %s`。完整句子用一个 key，避免按中文词序拼接英文。
复数 helper 把数量放在第一个参数：英文数量 1 选择 `.one`，其他情况选择 `.other`；中文选择 `.other`。两份文件都定义两个 key，中文可都写 `%s 项`，英文分别写 `%s item`、`%s items`。不使用 ICU 消息语法。
普通文本用 `Lang.t`；插入已有 HTML 片段的文案用 `Lang.html`，它会转义标记字符。字体名用 `Fonts.byId(id).name(document)`，注册表选择器用 `GameRegistry.entries(document)`。用户输入和服务端数据不按内容猜测翻译。

## 语言、回退与验证

游戏跟随当前语言与资源包；预览器读取同一份 JSON：

```sh
java -cp "preview/build/install/preview/lib/*" dev.oriel.preview.Preview kit/src/main/resources/assets/oriel/ui/gallery.html --lang en_us --snapshot /workspace/en-gallery.png
java -cp "preview/build/install/preview/lib/*" dev.oriel.preview.Preview --check kit/src/main/resources/assets/oriel/ui --lang en_us
```

查找顺序是 **当前语言 → zh_cn → key 本身**。回退产生 `missing-translation`，每文档、语言、key 只报一次；`checkUi` 列出诊断，`--strict` 会失败。参数不匹配产生 `invalid-translation`。资源包文案优先于库默认文件；原版物品等外部数据保持宿主原有翻译行为。
引擎仅依赖 `Host.language()` 与 `Host.translation(locale, key)`，不依赖 MC。游戏与预览器在语言变化后重载页面，保留未提交编辑、设置选择、物品槽及音乐位置。修改 JSON 后重新构建或重载资源；修改措辞不要重命名 key。

```sh
./gradlew --offline compileJava test :preview:checkUi
```
