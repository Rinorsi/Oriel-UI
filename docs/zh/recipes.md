# 界面配方（布局套路）

做新界面先挑布局套路。参数与接线查 [组件手册](components.md)，不要为拿清单先翻源码；完整流程见 [制作指南](ui-workflow.md)。下方结构片段是布局示意，省略号必须替换，不能直接当完整页面执行。游戏里 `/oriel showcase <名字>` 可看现成页面。

## 选哪个

| 你要做的 | 套路 | 对照页面 |
|---|---|---|
| 模组首页、菜单、入口 | A 全屏拼贴 | `gallery` |
| 有很多物品/格子要整理 | B 窗体三栏 | `inventory` |
| 一个动作为中心的玩法界面 | C 舞台 + 侧栏 | `forge`、`music` |
| 设置、文档、图鉴、目录 | D 列表 + 实时预览 | `settings`、`catalog` |
| 编辑器、工具 | E 四区工作台 | `editor` |
| 游戏中常驻信息 | F HUD 紧凑栏 + 展开 | `potions` |

## A 全屏拼贴（bento）

不放窗体，整屏一个顶栏 + 网格。网格里的块大小不一：一个 2×2 的主视觉，竖长块放实体，横长块放实时小组件，小块放数字。

```html
<div class="o-app"><div class="home">
  <div class="top">品牌 · 导航(m-indicator) · 主题 · 关闭</div>
  <div class="bento">   <!-- grid-template-columns: 2fr 2fr 1.5fr 1.5fr; rows: 1fr 1fr .9fr -->
    <div class="card hero o-tile m-spot">  <scene …>（3D 主视觉） + 渐变遮罩 + 标题文案 + 按钮</div>
    <div class="card o-tile hot m-spot" data-go="inventory" data-zoom>…</div>
  </div>
</div></div>
```

- 主视觉要会动：转动的 `<scene>` 或 `<model>`，一个粒子画布就够了。
- 动态用于主视觉和必要反馈；常驻动画遵守动效预算，静态内容同样可用。
- 文字压在 3D 上时，加一层从左到右的渐变遮罩（`.scrim`）保证可读。
- 点块用 `data-zoom` 转场。

## B 窗体三栏

`.o-window` 里：左栏角色/对象（3D），中栏主内容（格子网格 + 分类页签），右栏详情（悬停时 3D 转动 + 属性），底栏操作与状态。

- 中栏用 `o-seg` 带图标的分类；格子按稀有度上光圈。
- 右栏平时放"总览"，不要留空。
- 小屏（`max-width: 560px`）收起左栏。

## C 舞台 + 侧栏

主区是一个有光源的舞台（深色渐变 + 一团暖光），3D 主体放中间，操作条贴舞台下沿；侧栏记分/队列；底栏是大按钮。

- 舞台背景用"环境光 + 地平线"两层渐变，主体后面加光晕。
- 每个操作有强反馈：震屏 `fx-shake`、闪光、粒子爆发、判定文字弹出。
- 结果用 `m-modal` 弹出，带稀有度框和扫光。

## D 列表 + 实时预览

左边带图标的列表（选中项有左侧光条），右边是内容，切换时 `m-slide-left`；有"预览"需求时在最右放一栏实时预览。

- 列表项右边放数量或修改数角标（`o-badge`）。
- 内容区用 `o-caps` 小标题分组，行用 `ore-row`，不要每组再套一个块。

## E 四区工作台

标题栏放工具按钮（撤销/重做/复制/删除/预览/导出）；左：组件库 + 可搜索的树；中：画板（点阵背景）；右：属性检查器；底：状态栏（选择数、坐标、历史步数、快捷键提示）。

- 改动都进撤销历史；危险操作给明确反馈。
- 所有编辑都改工作副本，保存前原数据不动。

## F HUD 紧凑栏 + 展开

画在世界上，全部用玻璃面板（`panel_glass.png`）。平时只有一排图标格（带进度/倒计时），有新东西时弹出一张卡片再收回；把手或快捷键展开完整面板。

- 常驻部分越小越好，文字只留数字。
- 颜色只表达状态（增益绿、减益红、中性金）。

## 通用检查（做完对照）

1. `./gradlew :preview:checkUi`：没有错误、缺图，没有 `design:` 警告。
2. 一眼能看出：这屏最重要的东西是什么（只有一个视觉焦点）。
3. 每个可点的东西都有悬停和按下反馈；键盘 Tab 能走到。
4. 亮色主题下也看一遍；427×240 小窗口下不溢出。
