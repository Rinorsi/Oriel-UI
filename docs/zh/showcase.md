# Showcase 源码导览：每个效果是怎么做的

Showcase 是 Oriel 的**主参考库**：8 个整页示例 + 4 个基础演示，全部是普通的 HTML/CSS/JS，几乎不依赖 Java，源码里有大量写给人看的注释。要做类似的效果，**直接打开对应页面的源码照着读、照着改**，不要从零发明。模板中心里的 9 个官方风格模板（`kit/.../ui/styles/`）和各预设页（设置、背包、锻造等）是**次级参考**：它们展示"整套界面风格"和"控制器写法"，不是效果的出处。

## 在哪里

| 内容 | 源码 | 游戏里看 |
|---|---|---|
| 8 个展示页 + 共用样式 | `common/src/main/resources/assets/oriel/oriel/showcase/`（`*.html`、`showcase.css`） | 模板中心 → 演示；`/oriel showcase <页面>` |
| 4 个基础演示、标题卡、toast、箱子 | `common/src/main/resources/assets/oriel/oriel/demo/` | 模板中心 → 演示；`/oriel showcase layout\|animation\|livedata\|forms\|titlecard\|toast\|chest` |
| 生物图鉴的游戏数据 | `common/src/main/java/dev/oriel/mod/internal/client/showcase/Mobdex.java` | 同上 |
| 发布 jar 里 | `assets/oriel/oriel/showcase/`、`assets/oriel/oriel/demo/`（解压即可读） | |

下面的行号是写本文时的位置；源码改动后行号会移，**按注释里的关键词搜索**最可靠。

## 怎么复用到你的模组

1. 把要的 `*.html`**和同目录的 `showcase.css`**（8 个展示页都链接它）复制到你模组的 `assets/<你的模组id>/oriel/` 下。页面里引用的是 `minecraft:` 原版纹理和 `oriel:` 库资源，不用改；引用同目录文件用相对路径。
2. Java 里 `OrielScreens.open("<模组id>:oriel/shop.html")`，或游戏里 `/oriel open <模组id>:oriel/shop.html`。想先预览，放进 `config/oriel/my-pages/` 即可（见 [快速入门](quickstart.md)）。
3. 页面是否要 Java：**只有两处**。生物图鉴要游戏推送 `oriel.data.mobs`（`Mobdex.java` 就是这个推送，约 160 行，可照抄）；伙伴控制台里的对话是用关键词假装回复的，真要接模型就把 `oriel.send('chat', text)` 接到你的服务端，见 [服务端与容器](server.md)。小屋页还引用库自带的结构文件 `oriel:structures/cottage.nbt`，库装着就在，不用复制。其余页面复制即可运行。
4. 想要库的动效（涟漪、聚光、计数），在 `<html>` 上加 `data-oriel-shell`，见 [做页面前先读](page-rules.md)。

## 展示页：每页学什么

### 标题画面 `showcase/title.html`（643 行）：纯 CSS 的动态场景
- 昼夜循环的多层天空、**星星由脚本生成、各自闪烁**（约 56 行起）；流星一条渐变条（82）。
- **只用 box-shadow 画像素物**：鸟（100）、云块、山峰（223）、云杉树——一个 2×3 的盒子，用多层无模糊阴影叠成 27px 高的树（264–280），不用图片。
- **视差**：每层山是两倍宽的条带，里面两份相同的瓦片，滑动条带无缝循环（169–196）；鼠标视差在脚本末尾（628）。
- 标题 3D 挤出 = 四层逐级变暗的 1px 阴影（350）；字母**依次高亮的扫光**（357）；倾斜 -20° 并脉动的 splash（378）。
- 毛玻璃面板（400）、菜单行逐条浮入（419，注意用 `backwards` 不用 `both`）、悬停右滑发光（443）。
- 脚本：带种子的随机数（534），保证每次打开的风景一样；`addTile` 复制瓦片做无缝循环（551）。

### HUD 套件 `showcase/hud.html`（851 行）：HUD 叠加层的全套零件
- 罗盘（95–130）：标签按方位居中，脚本每帧滑动刻度、按距离淡出标签（730）。
- Boss 血条：原版紫色轨道里放自己的填充（177）；**无限滚动的渐变填充**（195）；浮起消失的伤害数字（222，脚本 763 生成、动画结束删除）。
- 任务目标列表：每项一个网格（268）；带扫光的细进度条（324）；toast 的**离场先滑出再折叠高度**，下面的自动补位（384）。
- 状态效果（433）、原版风格血量/饥饿/快捷栏（469）、**心跳 lub-dub 涟漪**（502）、描边数字（533 用四层阴影）。
- 模拟战斗节奏（794）、toast 约 5 秒后自动离场（816）。

### 商人集市 `showcase/shop.html`（822 行）：卡片与交易
- 靛蓝布料的斜织纹（27）、条纹加扇形边（34，渐变平铺）、暖光闪烁（62）。
- **一条下划线滑到当前标签下**：脚本只改位置，CSS transition 滑动（157，脚本 739）。
- 卡片悬停：抬起、放大、点亮边框、物品起伏（244）；物品放大正好 2 倍保持清晰（274）。
- **渐变边框**：透明边框 + 背景多层分别裁到不同盒子（315）；传奇物品常驻慢速漂浮（350）。
- 特效层：物品飞入背包的弧线、礼花、toast（508，脚本 763）；数字滚动（724）。

### 生物图鉴 `showcase/mobdex.html`（1146 行）：数据驱动的掌机
- 外壳：**第一层阴影是厚度，第二层是落影**（48）；模制接缝=一条暗线加一条亮线（67）；喇叭栅格=重复渐变（149）。
- 左屏：搜索、分类筛选、编号列表；**列表底部渐隐**而不是硬切（213）；行逐条滑入（323）。
- 全息舞台：聚光、地板网格、角标、扫描线、转台（434）；`-mc-yaw` 用 `@keyframes` 自转，悬停暂停（461）；选中时用 `:key` 重建元素，让一次性闪光动画重播（507，模板 758）。
- 数据：`oriel.data.mobs` 由 `Mobdex.java` 推送，`FLAVOUR` 给原版生物补手写条目（839）；类别色通过 `--c` 传给 CSS（942）。
- 从外部指定打开哪只：数据 `{start: {mob: 'creeper', filter: 'hostile'}}`（995）。

### 日志 `showcase/journal.html`（1025 行）：书、纸和墨水
- 皮革封面（67）、纸张与书脊折痕（101、142）、花边分隔=两条渐隐线加旋转方块（182）。
- 荧光笔选中（216）、墨水进度条（250）、**蜡封**（306，径向渐变加不规则边）、首字花饰带金箔扫光（333）、点线引导（447）。
- **地图**：9px 的 CSS 网格，每格一个 div，颜色由脚本里的小噪声函数决定（469）；虚线轨迹旋转到位（515）；比例尺（572）。
- 翻页：纸张在脚本驱动下抬起（585）；缎带尾 = 两个边框三角形（636）；按任务 `:key` 切换，让墨水动画重播（752）。

### 伙伴控制台 `showcase/console.html`（817 行）：终端风格的对话与任务
- 角标 = 两个对角的伪元素（66）；状态环 = 上、右边框点亮并永远旋转，"思考"时加速变琥珀色（115、137）。
- 对话：打字中的三点依次弹跳（318）；新消息出现后滚到底（666）；逐字输出与权限询问（691）。
- 任务：整体进度条的条纹**靠内层条带循环位移**（439）；当前任务的小转圈（496）；任务列表自动滚到进行中的一项（716）。
- 真实接入：`oriel.send('chat', text)` 发给服务端；这里用关键词假回复占位（773）。

### 3D 转台 `showcase/models.html`（273 行）：方块、物品、生物的 3D
- 无脚本，纯标记：`<model block="…">`、`<model item="…">`、`<entity id="…">`，一组固定角度便于和背包图标对比。
- 展示格：台座光晕加底部标签（65）；大舞台**拖动旋转、悬停摆动并俯视**（112）；半身像在画框底部渐隐（200）。

### 小屋 `showcase/scene.html`（523 行）：会自己搭起来的场景
- 场景占满整页，其余界面浮在上面（24）；**还没搭的步骤是完全透明的组**（透明的组既不画也不被点中，52）。
- 标注是场景里的 HTML（93）；建造者朝向按 Minecraft 的 yaw 计算（362），用"最短方向"转向，因为 `-mc-yaw` 的过渡按数值走（401）。
- **分层切片**：每层一组，第一次要用时才创建（446）；可以带 `{"start": {"step": 3}}` 从某一步打开（515）。

## 基础演示 `demo/`（每页很短，适合新手）

| 页面 | 学什么 |
|---|---|
| `layout.html` | flexbox 的 `justify-content`（7）、带命名区域的网格仪表盘（28）、随窗口宽度重排的自动填充瓦片（59） |
| `animation.html` | 关键帧、过渡、延迟 |
| `templates.html` | 模板与数据绑定：循环变量 → `oriel.data` → 状态 → 全局的取值顺序（94）；回车提交表单（71）；服务端会话下用 `refresh` 推数据（116） |
| `settings.html` | 不加样式的控件本来就是原版外观，页面只负责排版（7） |
| `hud.html` / `toast.html` | 标题卡淡入淡出叠加层；带按钮的交互 toast（按 T 然后点它） |
| `chest.html` | `<slot>` 绑定真实箱子槽位，见 [容器页面](containers.md) |
